# 💰 Pocket Tracker CLI

Simple project Python untuk mencatat pengeluaran harian dan mengukur tingkat keborosan langsung dari terminal/CLI.

## 🚀 Running di Termux / Terminal
```bash
pkg install python git -y
git clone [https://github.com/rhieomanuel/pocket-tracker.git](https://github.com/rhieomanuel/pocket-tracker.git)
cd pocket-tracker
pip install -r requirements.txt
python main.py
